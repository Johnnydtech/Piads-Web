# Airbnb Host Recruitment — Ad Copy & Outreach

Goal: recruit Airbnb/STR hosts as PiAds venues. Two distinct audiences need different angles — don't mix them in one ad:

- **Single-unit hosts** — pitch is guest experience (fewer repetitive questions, better reviews), not ad income. Being honest about this matters: a one-unit screen doesn't see enough guest volume to be a real revenue play, and overselling it will show up as a trust problem later. See `/blog/is-a-digital-welcome-screen-worth-it-for-one-airbnb`.
- **Multi-unit buildings / STR property managers** — pitch leads with revenue (local ad marketplace, 70% kept per booking) because the guest volume is real. See `/blog/digital-signage-for-short-term-rentals`.

Facts to keep consistent across every variant below: **$10 per screen per month, every feature included, no contracts. Venues keep 70% of every ad booking.**

## Organic / community post (Airbnb host Facebook groups, forums)

Disclosure required — same rule as the Reddit/Quora bank: answer honestly first, disclose affiliation, never copy-paste the same text twice.

**Prompt to answer:** "Anyone have a good setup for a welcome screen / guest info TV?"

Honest answer: a laminated sheet works fine if you don't mind reprinting it every time something changes. If you want it to update itself, digital signage software is the category — most run $10-20/screen/month. I build one (PiAds) that's Fire TV/Android/browser-based, no new hardware if you've already got a stick in the unit. For a single unit, I'd set expectations honestly: it's worth it for guest experience (wifi, checkout, local picks all on-screen, editable from your phone) — don't expect meaningful ad income unless you're running a multi-unit building with real guest volume, since that's where the local-ad-marketplace side actually pays off.

## Notes for whoever runs these

- Never state a specific revenue number for a single-unit host — the honest range is "a few dollars a month, maybe," which doesn't make a good ad. Lead single-unit creative with guest experience, not money.
- Multi-unit revenue ranges ($100-300/mo for 6-15 units) come from `/blog/digital-signage-for-short-term-rentals` — keep any ad claims consistent with that post so a host who clicks through doesn't see a contradicting number.
- If a blog post's pricing or revenue-share language ever changes, update it here too — this doc duplicates those facts rather than linking live, so it drifts if only one side gets fixed.
